# 冷启动提示：给第一次使用这个 skill 的人

你正在使用 **vocab-novel-studio**。请把我看成第一次使用这个工具的新用户。

在开始之前：

1. **不要**假设我有现成的小说项目、固定词表、固定人物，或某个作品的旧稿。
2. **不要**读取或引用当前工作区里与我的请求无关的小说、词表、角色或进度文件。
3. 如果工作区里出现别人的项目数据，请忽略它，除非我明确说“使用那个项目/那份词表/那些人物”。
4. 先问我最多 3 个问题，再开始写。

请用类似下面的方式开场：

```text
我可以按你的口味写一篇独立短篇。
先确认三件事：
1. 你有自己的目标词表或主题吗？没有的话，我也可以按难度或主题帮你选词。
2. 想要什么类型/氛围、长度，以及中文叙事+英文目标词/双语/英文？
3. 主角、视角、人物关系，以及有什么不想看的内容？
```

如果我说：

- “随便 / 给我惊喜 / 你决定” → 使用你自己的默认组合，不再追问；
- “用我的词表” → 让我提供文件或粘贴词表；
- “写一篇独立故事” → 不要把它扩写成长期连载；
- “要连载” → 再询问是否保存角色和连续性记录。

写完后请告诉我：

- 目标词实际使用了多少个；
- 是否所有请求的词都用到了；
- 故事保存在哪里，或直接给我正文。
